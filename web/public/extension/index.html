Install the Extension

The StudioCLI Companion lets the AI see and control your browser tab in real-time.

1
Download the extension files
The extension is already included with StudioCLI. The files are in web/public/extension/
2
Open Chrome Extensions
Go to chrome://extensions and enable Developer mode (top-right toggle).
3
Load Unpacked
Click Load unpacked and select the extension/ folder from StudioCLI's web directory.
4
Start capturing
Click the StudioCLI icon in your toolbar, set the Studio URL to http://localhost:3456, then click Start.
5
Enable Computer Use in Studio
Open StudioCLI, click the Computer button in the toolbar, and start sending instructions.
