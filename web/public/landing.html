Can you write a Python function that fetches JSON from a URL using only stdlib?

Sure! Here's a clean implementation using urllib.request — no third-party deps required:

import json
from urllib.request import urlopen

def fetch_json(url: str) -> dict:
    with urlopen(url) as r:
        return json.loads(r.read())
